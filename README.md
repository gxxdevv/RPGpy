# RPGpy

Um RPG de terminal desenvolvido
em Python para praticar programação
e organização de projetos.

## Sobre o projeto

O RPGpy é um projeto pessoal
criado para colocar em prática
conceitos de Python, como:

- Estruturas de controle
- Funções
- Listas e dicionários
- Organização em módulos
- Git e GitHub

  O projeto também será utilizado
  para estudar e implementar
  **Programação Orientada a
  Objetos (POO)** futuramente.

## Tecnologias
  
- Python
- Git
- GitHub
